# Tasks

One file per phase exit and per lane package, named `P<phase>-<what>.md`, with front matter `title:` and `status:`
(`open`, `review`, `done`). A phase counts as built when its "Exit..." task is in review or done
(tools/data/check_rules_docs.py reads this). The phases and their exits are in the plan, section 10.4. None yet: Phase 0's exit
task is written when Ashwin signs off the foundation.
